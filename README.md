# QuantumCircuit

Example projects and small exercises in **quantum computing**, using both [Qiskit](https://qiskit.org/) (Python) and [Q#](https://learn.microsoft.com/en-us/azure/quantum/qsharp-overview) (Microsoft Quantum Development Kit).

## 🧠 Overview

This repository contains experiments, demos, and example code illustrating basic quantum computing concepts such as:

- Qubits, superposition, and measurement  
- Quantum gates and simple circuits  
- Entanglement and interference  
- Grover’s search algorithm  
- Shor’s algorithm (conceptual demo)  
- Noise and decoherence simulation  

The repository was created in connection with a **Quantum Computing lecture** held during Zenta AB’s *Competence Day* on **November 26, 2021**.
